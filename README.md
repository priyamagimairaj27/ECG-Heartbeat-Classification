# ECG Heartbeat Classification Using Deep Learning

## Project Overview
This project uses Deep Learning and Convolutional Neural Networks (CNN)
to classify ECG heartbeat patterns into different categories.

The objective is to explore how deep learning can support automated
heartbeat classification using electrocardiogram (ECG) signals.

## Technologies Used
- Python
- TensorFlow / Keras
- Convolutional Neural Networks (CNN)
- NumPy
- Pandas
- Matplotlib
- Google Colab

## Dataset
The project uses the MIT-BIH heartbeat dataset, containing ECG
heartbeat samples belonging to multiple classification categories.

## Model
A CNN-based deep learning model is trained to recognize patterns
in ECG heartbeat signals and predict their corresponding classes.

## Results
Test Accuracy: 96.44%

## Project Structure
- ECG_Heartbeat_Classification.ipynb — Main project notebook

## How to Run
1. Download the notebook.
2. Open it in Google Colab.
3. Install the required dependencies if necessary.
4. Run the notebook cells in order.
